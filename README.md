# PixelPetal Designs – Terms of Use

A single-page, static Terms of Use site (HTML5, CSS3, vanilla JS). No build step, no external requests, no paid services.

## Before you publish: fill in these placeholders
1. **Contact email** – in `index.html`, replace every `your-email@example.com` (4 places).
2. **Credit links** – the page says "the PixelPetal Designs website or shop". If you want actual hyperlinks, add your URLs in the Credit section and the other credit mentions.
3. **Review the legal text** – see `REVIEW-NOTES.md`. Have a qualified professional review it before relying on it.

## Publish on GitHub Pages (free)
1. Create a GitHub account and a **new public repository** (e.g. `pixelpetal-terms`).
2. Upload `index.html`, `style.css` and `script.js` to the repository root (**Add file → Upload files**), then commit.
3. Go to **Settings → Pages**. Under *Build and deployment*, set **Source: Deploy from a branch**, choose branch **main** and folder **/ (root)**, then **Save**.
4. Wait 1–2 minutes. Your site appears at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Update the date
Edit "Last updated" in the footer of `index.html` whenever you change the terms.

## Files
- `index.html` – content and structure
- `style.css` – design (cream, pink, sage and beige palette; system fonts)
- `script.js` – back-to-top button only
